# Archived Reflection history

This directory preserves the former Reflection queue, allocation metadata and evidence byte for
byte after the Issue-system refactor. The four open records R-071 through R-074 were **not**
reclassified, resolved or promoted into Issues. Their relative evidence links remain local to this
archive. Historical text describes the software and decisions at its recorded time, not the current
Framework contract.

This archive is read-only historical material for normal Concorde workers. It is not an active
queue, a repair authorization or current verification evidence. To continue an old problem, report
an explicit new Issue and cite the appropriate archived record. Do not restart the retired triage
workflow or silently treat an old plan as an approved resolution.
