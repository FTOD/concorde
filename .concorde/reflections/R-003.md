# R-003 · Browser visual review unavailable for delivery diagrams

## Context

This problem was recorded during `implement` for
`feature.concorde.workflow.accept-milestone` and concerns `specs/concorde/architecture.md`.

## Expected

Archify visual-check captures containment and light/dark screenshots for every changed delivered workflow view.

## Observed

All three sources passed 9/9 showcase validation and HTML delivery, but visual-check skipped because Chrome/Chromium is unavailable.

## Impact

Recorded effect: deferred. Preserved the deterministic delivery receipts and marked browser containment and perceptual review pending.

## Evidence

Primary concern: `specs/concorde/architecture.md`.

## Triage Analysis

Migrated triage record: the prior log identified the gap between the expected and observed behavior and recorded this workflow response: Preserved the deterministic delivery receipts and marked browser containment and perceptual review pending.

## Proposed Resolution

Provide Chrome/Chromium in the development validation environment or set `ARCHIFY_CHROME` to a supported executable.

## Intervention Rationale

需要你提供或批准受支持的浏览器运行环境；结构校验可以自动完成，但最终视觉验收不能由无浏览器的 agent 代替。

## User Comments

- 2026-09-03 — Resolved. The browser is supplied through `ARCHIFY_CHROME` pointing at Playwright's
  Chromium; the setup is documented under Recommended software in `docs/quick-start.md`, and all seven
  module overviews passed visual-check with it.
