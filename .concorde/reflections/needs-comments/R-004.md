# R-004 · Temporary Codex self-host refresh hit registry mismatch

## Context

This problem was recorded during `implement` for
`feature.concorde.workflow.accept-milestone` and concerns `scripts/development/sync-agent-surfaces.py`.

## Expected

Temporarily selecting Codex lets self-host refresh that integration while preserving the current Claude materialization.

## Observed

Codex preflight succeeded, but apply detected Spec Kit registry entries that did not match the temporary composition and rolled back the owned scope.

## Impact

Recorded effect: worked-around. Kept the rollback, used public component materialization for Codex, then restored and reverified the configured Claude integration.

## Evidence

Primary concern: `scripts/development/sync-agent-surfaces.py`.

## Triage Analysis

Migrated triage record: the prior log identified the gap between the expected and observed behavior and recorded this workflow response: Kept the rollback, used public component materialization for Codex, then restored and reverified the configured Claude integration.

## Proposed Resolution

Let self-host explicitly refresh an inactive installed integration without temporarily changing the project's active integration.

## Intervention Rationale

需要你决定是否允许刷新非当前 active integration，以及是否接受该集成的安装面成为维护范围。
