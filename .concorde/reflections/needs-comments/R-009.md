# R-009 · Planning guidance writes contracts outside temporal attempt memory

## Context

This problem was recorded during `plan` for
`feature.concorde.workflow.plan-delivery` and concerns `skills/concorde-plan-author/SKILL.md`.

## Expected

Planning keeps proposed contract work in the selected attempt and schedules any durable contract mutation for implementation.

## Observed

The plan command directs Phase 1 to write feature-root `contracts/`, although child FR-007 and parent FR-015 prohibit planning from updating durable sources and the module reference classifies `attempt/contracts/**` as temporal.

## Impact

Recorded effect: worked-around. Created no child contract for this milestone and planned to reconcile the maintained command/template guidance with temporal contract proposals.

## Evidence

Primary concern: `skills/concorde-plan-author/SKILL.md`.
