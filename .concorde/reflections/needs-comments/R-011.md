# R-011 · Partial Codex projection backup exposed lower-layer skills

## Context

This problem was recorded during `implement` for
`feature.concorde.workflow.plan-delivery` and concerns `feature.skills.project-workflow`.

Refreshing the three changed Codex skills preserves every other Concorde preset winner while Claude remains the configured integration.
