# R-061 · General code review has no read-only implementation invocation

## Context

P7 permits implementation source to enter cognition only during an implementation invocation and
explicitly classifies code inspection, debugging and code review as implementation work. The host
already demonstrates one read-only implementation subtype for Reflection investigation: it grants
selected component code, supplies reflection evidence, disables writes and starts a fresh process.

Users also request ordinary branch review, diagnosis or implementation inspection when no Reflection
record and no active change attempt exists.

## Expected

Every supported request that requires source inspection has a public host path that classifies it as
implementation cognition, selects one owning Service or Module, grants only that implementation
scope, disables writes when the task is observational and returns a declared findings contract. It
does not require a fake mutation task or a pre-existing Reflection merely to obtain read-only code
authority.

## Observed

`AGENT_OPERATIONS` maps `concorde-analyze` to the `context-solve` phase and the
`concorde-context-assessor` role, which cannot see code. `concorde-implement` and
`concorde-converge` map to implementation, but `Invocation.implement` rejects a call without an
active change ID, authored plan and tasks. Its normal policy also grants writes to the selected
implementation paths.

Reflection investigation is the only shipped read-only implementation path. It requires selected
Reflection records and has a specialized result schema and lifecycle; it cannot honestly represent
an unrelated code review request.

## Impact

A normal code-review or diagnostic request cannot comply with both the user's task and P7. It must
either inspect code outside the Operation host, manufacture lifecycle artifacts that imply mutation,
misuse the Reflection workflow, or stop as unsupported. This also makes it difficult to investigate
a failed deterministic check before a Reflection has been authored.

## Evidence

- `protocol/principles.md` P7 says code inspection, debugging and code review require an
  implementation invocation.
- `src/concorde/capabilities/protocol_contracts.py:23-35` maps analyze to context solving rather than
  implementation.
- `src/concorde/capabilities/scoped_operations.py:318-330` requires an active attempt and tasks before
  starting a normal implementation worker.
- `src/concorde/reflections/scoped_triage.py` invokes the implementation worker read-only only for a
  typed Reflection selection.
- `specs/concorde/services/reflection-boundary.md` explicitly scopes that exception to selected
  Reflection records.
