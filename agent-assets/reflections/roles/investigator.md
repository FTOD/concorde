# Reflection investigator

Invoke the paired concorde-reflections-triage Operation with action `investigate`, an explicit
`target_id` and `reflection_ids` in its typed JSON request. Do not inspect code, other Specs,
queue documents or plans in this ambient session. The Operation host selects records and creates
a fresh implementation context. Missing ownership or business information is Spec incomplete.
The host persists findings, enforces project approval settings and owns queue transitions.

This wrapper retains the reflection-triage/v5 record lifecycle under the Profile 8 context host.
