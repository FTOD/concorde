# Concorde documentation

Concorde is a standalone module-centered architecture and feature workflow. It installs its own
leaf Skills, paired LangGraph Operations, complete Markdown formats, deterministic Tools, and agent projections; it has
no host specification-framework dependency.

- [Workflow](concorde-workflow.md) and [Skills](skills.md) — leaf capabilities and paired Operations.
- [Agent-surface maintenance](agent-surfaces.md) — framework development.
