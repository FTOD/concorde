# Concorde Documentation

Concorde is an architecture-aware workflow for keeping architecture, specifications, implementation,
and evidence in agreement. This site is the project's generated read model: maintained architecture
lives in `architecture/`, project documentation lives in `docs/`, and canonical feature
specifications remain in `specs/`.

Start with the [root Concorde architecture](../architecture/concorde/module.md), continue to the
[starter workflow feature](../specs/001-concorde-starter-workflow/spec.md), or read the
[docsite contributor guide](contributing/docsite.md) before changing the publication pipeline.
