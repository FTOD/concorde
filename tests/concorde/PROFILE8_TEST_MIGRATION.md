# Profile 8 regression migration

This cutover retires assertions for public leaf Skills, Profile 7 positional Feature workspace
arguments, ancestor/code planning context, seven recursive architecture.md files and Delivery
Proposal 9 CLI artifacts. These contracts contradict the approved Profile 8 behavior.

| Retired contract family | Replacement behavioral coverage |
| --- | --- |
| Ambient leaf/Operation handoffs, code-visible planning | specification/test_scoped_protocol.py; test_boundaries.py |
| Feature-path workspace and attempt CLI | Typed paired CLI, intent/revision binding, worktree tests |
| Source/installed public leaf surfaces | test_distribution.py plus retained installer ownership/rollback and agent-surface sync suites |
| Reflection Operation topology | test_scope_and_reflections.py plus retained record/parser/configuration/queue tests |
| Module-only self architecture and templates | Explicit self registry/package validation and scoped publication suites |

Native permission compilation, execution attestation/replay, managed-runtime provisioning, installer
rollback, reflection parsing/disposition and deterministic legacy Profile 7 utility tests are retained.
Only the external model process is substituted in the new acceptance fixture; the actual host,
LangGraph, typed adapters, code mutation, subprocess checks and delivery execute.
